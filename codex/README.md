# Flate i Codex

    codex mcp add flate --url https://mcp-production-e390.up.railway.app/mcp
    codex mcp login flate

Lim innholdet i `AGENTS.snippet.md` inn i repoets `AGENTS.md`, så vet Codex hvordan runder skal gjennomføres. Alternativ uten OAuth: `codex mcp add flate --url … --bearer-token fl_…` med et prosjekt-token fra Flate-dashboardet.
